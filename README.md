# LØFT – styrketræning for begyndere

Mobil web-app (PWA) med færdige 4-ugers programmer, pausetimer, automatisk vægtlog og grafer over fremgang.

- På computer vises appen i en telefon-ramme (`desktop.html`) med QR-kode.
- På mobil åbner den som normal app og kan gemmes på hjemmeskærmen (virker også offline).
- Data gemmes lokalt på enheden (localStorage).

Kør lokalt: `python3 -m http.server` og åbn http://localhost:8000
